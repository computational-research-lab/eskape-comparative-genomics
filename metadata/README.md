# Metadata

## strain_accessions.csv

This file maps each of the 120 analyzed strains to its NCBI Genome database accession.

| Column | Description |
|--------|-------------|
| `Species` | Species group (Acinetobacter, Enterobacter, Enterococcus, Klebsiella, Pseudomonas, Staphylococcus) |
| `Name` | Strain identifier used throughout the pipeline |
| `NCBI_Accession` | NCBI assembly accession (e.g., GCF_000... or GCA_000...) |
| `NCBI_Assembly` | Assembly name (optional) |
| `URL` | Direct link to NCBI assembly page |

All 120 strains have been annotated with their NCBI accession numbers, assembly names, and direct URLs.
